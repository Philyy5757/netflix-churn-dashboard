NETFLIX CHURN DASHBOARD

1. Double-click index.html to open it in Chrome, Edge, or Firefox.
2. Use country and plan dropdowns to filter the dashboard.
3. Click Upload CSV to analyze your own dataset.
4. Click Reset demo to return to synthetic sample data.

CSV: requires churned column (0/1, true/false, yes/no).
Optional: customer_id, country, subscription_type (or subscription_plan), last_login_days.

All CSV processing is local in your browser. No server or installation is required.
Default sample records are synthetic, not actual Netflix records.
